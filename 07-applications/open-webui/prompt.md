# FARCI — prompt Open WebUI

Ce fichier est le prompt système pour Open WebUI.
Il doit être **identique** à `common/prompts/extraction_v1.md`.

## Configuration

Dans Open WebUI :
1. Admin → Settings → Prompts
2. Créer un nouveau prompt avec le contenu ci-dessous
3. L'assigner au modèle `med-extraction`

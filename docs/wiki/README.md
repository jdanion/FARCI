# FARCI — Wiki des équipes

Ce wiki contient un tutoriel pas à pas pour chaque équipe du workshop.

## Structure de chaque page

1. **Attendus pédagogiques** — ce que l'équipe doit comprendre
2. **Solution simple** — déploiement rapide via les scripts du dépôt
3. **Solution from scratch** — déploiement manuel pour approfondir

## Utilisation

Chaque page est autonome. Commencez par les **attendus pédagogiques** pour comprendre
le "pourquoi", puis choisissez la **solution simple** (scripts) ou la **solution
from scratch** (manuel) selon votre niveau.

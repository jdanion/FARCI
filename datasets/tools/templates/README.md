# Templates de documents FARCI

Ce dossier contient les gabarits des 4 types de documents synthétiques.

| Fichier | Document |
|---------|----------|
| `cro.md` | Compte rendu opératoire |
| `crap.md` | Compte rendu anatomopathologique |
| `crscan.md` | Compte rendu scanner |
| `lettre.md` | Lettre de sortie |

Ces gabarits sont utilisés par `render_pdf.py` pour générer les PDF.

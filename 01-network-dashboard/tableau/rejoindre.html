Rejoindre la salle FARCI

Vous arrivez sans avoir cloné le projet ? Tout est ici, servi par la machine du formateur, sans Internet. Comptez 5 minutes pour les étapes 1 à 4.

1Récupérer le projet

Avec git (Mac, Linux, Windows avec WSL) :

git clone http://HOTE/farci.git farci

Sans git : farci.tar.gz ou farci.zip, à décompresser. …

2Pointer vers la salle

cd farci && curl -o config/network.env http://HOTE/partage/network.env

Ce fichier contient seulement l'adresse de la salle et les ports : vous n'avez rien à modifier.

3Installer les dépendances Python

FARCI_WHEELS_URL=http://HOTE/partage/wheels/ ./bin/farci bootstrap

Mac (Intel ou Apple Silicon), Linux ou Windows avec WSL ; Python 3.11 à 3.13. …

4Vérifier

./bin/farci doctor

Attendu : « accueil de la salle : joignable ». Le tableau de la salle : /tableau.

5Votre brique : les images Docker

Seulement si votre équipe héberge une brique (étape 1). Téléchargez l'image de votre brique (votre fiche d'équipe dit laquelle), puis chargez-la :

PC Intel / AMD …
images x86
Mac Apple Silicon …
images arm64
curl -O http://HOTE/partage/offline-x86/images/NOM.tar && docker load -i NOM.tar

Le Wi-Fi de la salle est partagé : une image lourde prend plusieurs minutes. Si une clé USB circule, elle est plus rapide.

★Pas de machine utilisable ?

Vous participez quand même : en binôme pour l'étape 1, et pour l'étape 2 avec l'interface de discussion de la salle, dans un navigateur : Open WebUI.
